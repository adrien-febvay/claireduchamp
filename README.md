# www.claireduchamp.ch

This is the professional website of Claire Duchamp.

It is a React/Express application using Webpack, Babel, Typescript and SASS.

## Installation

Before it can be built and/or launched, it needs to be installed with `npm install` or `npm ci`.

**Important note:** At the moment, the project uses a version of `isomorphic-style-loader` that is not compatible with the version of React. You may have to use the option `--force` to install the dependencies.

## Configuration

The configuration files are located in the `conf` directory. There is one for the `development` mode, and one for the `production` mode.

To create the configuration files, type `npm run init`. It will copy the `template` files and rename them accordingly.

Beware that the `production` configuration file contains identifiers for the production services (GTM and web3forms). **ONLY use these values on the production machine.** If you want to test the built application, type `npm run dev build` (see _Development_ section below).

## Development

Type `npm run dev` to start the app in `development` mode.

It will run React's dev server, and it will be proxied by the Express back-end, which will also inject the SSR into the HTML generated by React. Both will restart/update upon changes in their source.

In addition, the `development` mode has some options to help testing the application. Type `npm run help` to get information on available options.

## Commit changes to Git

Before any Git commit, please type the following:
* `npm run test` to perform all checks below in one go.

Available checks:
* `npm run tsc` to check for typing errors.
* `npm run eslint` to check code quality.
* `npm run eslint-fix` to automatically normalize the code (when possible).
* `npm run stylelint` to check the CSS files.
* `npm run stylelint-fix` to automatically normalize the CSS files (when possible).

## Building, running production

Type `npm run build` to compile the client in its `dist` directory.

Type `npm run start` to launch in `production` mode once the build is ready.

## Cleaning

Type `npm run clean` to remove temporary directories.
